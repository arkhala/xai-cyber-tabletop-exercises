# xAI Cyber Tabletop Exercises

Dynamic cybersecurity tabletop exercise simulator powered by xAI API (Grok).

## Key Features
- **Dynamic Scenario Generation**: AI generates realistic scenarios on-the-fly based on common themes, recent news, and current vulnerabilities
- **Custom Scenario Support**: Enter your own idea and let the AI flesh it out into a full exercise
- Choose-your-own-adventure style gameplay
- Real-time action logging and decision recording
- Built-in CSIRT stand-up, incident reporting prompts
- Automatic generation of After-Action Report, Incident Memo to CISO, logs, etc.
- Streamlit GUI
